# BeeMod
This is an opensource project created by Run4fight for the Beesim server (play.beesim.gg).
Eventually it will have multiple QoL features.

# Features
For now, only a single feature is implemented, to make ingame buffs easier to read.
Use /beemod config for its settings 

# Requirements
To use this mod, you need to use :
> Fabric 0.19.5
> Minecraft 1.21.11
> Fabric API 0.141.6+1.21.11
